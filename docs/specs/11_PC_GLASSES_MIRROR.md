# PCでグラスの表示内容をライブ確認

2026-09-23のユーザー要求：スマートグラスの表示をPCでもリアルタイムに確認する。既存の実装・レビュー・マージ委任に従う追加要件。

## 受入条件と設計

- 人物一覧、質問、出典、音声状態のうち、G2 SDKが表示更新を受け付けた最新の内容をPCに転送する。未受付・破棄された表示を完成画面として扱わない。
- PCはアプリを動かす同じマシンの `http://localhost:4173/mirror.html` で閲覧。約500ms周期で最新画面を読み、送信側は静止画面でも5秒ごとに生存通知する。実際の通信遅延に加算される。
- 光学的な視界・カメラ映像ではなく、アプリの送信内容を再現する。SDK内部のフォント、ネイティブスクロール位置、眼鏡内での実表示成功をPCから証明するものではない。
- 認証済み端末だけが投稿できる。閲覧は同一PCのloopbackに限り公開トンネルからは拒否する。音声やAPIキーは送信しない。最新のみをメモリ保持し、2分で失効、セッション失効・終了で消去。
- 10秒以上更新がない場合は画面を古い状態として明示。送信停止・G2切断を表示する。ミラー側のエラーで音声認識・グラス表示を停止させない。
- 新しい有料APIは呼び出さない。人物検索、選択、マイクの操作は引き続きEven App側で行う。

## 検証

G2受付後の通知・拒否時の非通知、ミラー障害の分離、最新画面への集約、認証切替時の旧画面破棄、閲覧の接続元制限、失効と削除を自動試験する。実機でPCとの一致を確認した結果とは区別する。
