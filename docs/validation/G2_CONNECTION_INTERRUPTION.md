# 会話中の接続停止（2026-09-23）

[Issue #42](https://github.com/ima-work-git/ai-hack-agent/issues/42)、[仕様11追記](../specs/11_QUESTION_READABILITY_AND_PUBLIC_NAMES.md)。

ユーザー報告は会話中に一瞬「リンクが切れました」と出た可能性があるが、スマホに表示がなかったというもの。調査時点では公開status、ローカルstatus、トンネルreadyが全て正常。実機の過去イベントや原因は確認できていない。

コードでは画像・レイアウトにも2秒の期限が適用され、超過するとマイクとASRが停止し、再開不可なのに同じ画面での再開を案内していた。画像系だけ8秒へ分離し、復旧不可状態をUIへ伝える。スマホの停止理由表示は普通の状態表示とは別に残し、背景化イベントの到着順と両入力元を扱う。

関連231試験、型・サーバーimport・39文書の検査、productionビルドが成功。独立レビューで見つかったブラウザー背景化の通知順序による表示漏れは修正し、回帰試験が成功。画像とレイアウトが各3秒かかってもPCMが継続し、8秒超過後の古い画像・待機画面・再開を抑止する試験が成功。配布ファイルは index-B_m1GFgr.js。外部の有料API・実機の長時間会話試験は今回未実施。Bluetooth自体の切断防止や継続ASRの自動復旧を保証する変更ではない。
