# 01 課題・要求・MVP — 会話中の調査アシスタント

> 2026-09-22 / v0.2。ユーザーが採用したテーマを具体化した独自の仕様草案。公式AI-DLCの承認・状態を表す資料ではありません。テーマ・Even G2・既存接続方式の再利用は確定、MVP詳細・数値は提案です。未実装・未評価。

## 採用した意図

サービス名は未定。懇親会・打ち合わせの立ち話で出た人名や会社名をEven G2で捉え、AIがWeb・利用可能な公開SNSを調査して、会話を深める短い話題を視界に返す。

対象利用者は対面の会話中に相手の背景を調べたい参加者。課題仮説は、スマホ検索による会話の中断と、相手の活動を知らず質問の機会を逃すこと。約2人でCodex・AWS AI-DLCを使用し、既存G2試作の接続・表示方式を引き継ぐ。

## MVP案：1人について根拠のある話題を返す

音声処理の説明・同意確認と開始 → 最大30秒の音声から人名/会社名を抽出 → 対象照合（曖昧なら人が選択）→ 検索先を選択 → 公開情報収集 → 根拠照合、不足なら追加検索 → 1〜3枚の話題カード、または確認不能の表示。

名前が出た人物と目の前の相手は同一とは限らない。会話で調べたい対象を扱い、顔や声から本人を識別しない。

| 範囲 | 内容 |
| --- | --- |
| 必須 | G2音声・短文表示、スマホの手入力補正、会社/人物候補の照合、Web調査、根拠確認、停止・縮退・費用記録 |
| 最初の情報源 | 会社公式サイト、本人の公開プロフィール、登壇者紹介等 |
| SNS | X/Facebookはアクセス可能性を確認した連携だけ追加。利用できなくても公式サイトで成立させる |
| 話題 | 事業・公開活動・登壇、本人が公表した趣味、事実として確認できる共同活動 |
| 今回の対象外 | 常時録音、顔認識、非公開情報、ログイン制限回避、交友関係の推測、センシティブ属性推定、自動投稿/DM、CRMへの自動登録 |
| 人の判断 | 音声処理の開始/停止、曖昧な対象の確認、話題を実際の会話に使うか |

趣味・交友情報は必須出力にしない。写真やフォローから「親友」等を推測せず、共同登壇なら共同登壇と書く。見つからない情報を埋めず、事業等の確認できる話題を返す。

## カード例（架空デモ資料）

```text
対象：架空企業A / デモ人物A
公開活動：製品設計の勉強会に登壇
話題案：設計で一番難しかった点は？
出典：主催者紹介 [1] / 取得時刻
```

1枚ずつ表示し、根拠本文・URL・公表日/取得時刻はスマホで確認する。最大3枚、事実と質問案は各1文を基本とする。日本語の見切れと読みやすさを実機で確認する。

## 受入条件

| ID | Given / When | Then（観測する結果） | 判定 |
| --- | --- | --- | --- |
| REQ-001 | 説明/同意確認後に開始、停止または30秒経過 | 録音中表示、停止後の音声拒否、原音の永続保存なし。権限拒否時は手入力 | 未実施 |
| REQ-002 | 名前/会社を含む発言、聞き間違い、第三者への言及 | 抽出結果を修正でき、対象不明なら確認。黙って別人へ切り替えない | 未実施 |
| REQ-003 | 同姓同名・所属違い・同名SNS | 名前と所属の根拠を照合。曖昧な候補の情報を混ぜず、候補変更で旧結果を無効化 | 未実施 |
| REQ-004 | 根拠・矛盾・根拠不足が混在 | 採用事実に根拠URL・該当箇所・取得日時。不足は追加検索か棄却。最大3枚、ゼロ件も正常終了 | 未実施 |
| REQ-005 | G2表示、対象変更、切断/復帰 | 1枚ずつ表示、スマホで詳細。遅延した旧対象結果を送らない。切断時はスマホに縮退し実機表示成功と区別 | 未実施 |
| REQ-006 | 429/5xx/timeout、不正応答、SNS不可 | 上限内で復旧か情報源を縮退。「取得不可」と「情報がない」を区別 | 未実施 |
| REQ-007 | 費用・時間・回数の上限 | 新規呼出停止、検証済み部分結果か理由を表示。費用上限未設定ではlive開始不可 | 未実施 |
| REQ-008 | 外部命令・内部URL、セッション終了 | 不正操作/秘密送信を拒否。通常ログに個人データを残さず、終了時に削除要求 | 未実施 |
| REQ-009 | 架空データ評価セットを実行 | 品質・介入・時間・費用を計測し、実機/模擬・実API/固定データを明示 | 未実施 |

目標案：評価セット中の別人混同0件、出典欠落0件。対象確定から最初のカードまで中央値10秒以内、調査全体20秒で打切り。音声認識と確認待ちは別計測。いずれも未計測で、一般利用の無誤り保証ではない。
