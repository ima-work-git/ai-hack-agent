# 質問の識別・小文字表示と公開人物の名前検索

2026-09-23のユーザー要求。[Issue #40](https://github.com/ima-work-git/ai-hack-agent/issues/40)。既存の要件確認・実装・レビュー・マージ委任に従う追加変更であり、公式AI-DLCの未完了ゲートを承認済みに変更するものではない。

## 表示

スマホの4件の質問・出典詳細、G2の質問画面に「⭐️推奨質問：」を付け、根拠の事実と質問を見分けられるようにする。スマホは質問カードと出典詳細を一段階小さくする。質問の内容・根拠検証・出典の対応を変えない。

G2 SDK 0.0.12の標準TextContainerには文字サイズ指定がないため、質問・出典本文だけローカルCanvasで14pxに描画する。表示面576×144を左右288×144のPNGに分け、順番に転送する。本文はgrapheme単位で折り返し、4組の間隔を残す。行を削除したり、省略記号や横方向の圧縮で全文を詰めたりしない。

全文が収まらない、Canvasを利用できない、画像非対応の場合は標準文字へ戻す。長文による標準表示の後も、次の短文は画像を再試行する。画像の明示拒否時は接続中の画像利用をやめて標準文字に戻す。応答のない転送は後で完了する可能性があるため、タイムアウト時は音声・表示を停止して再接続を案内する既存の境界を維持する。

人物一覧・ヘッダー・音声状態は標準文字のままとし、ASRの状態更新だけで同じ本文画像を再転送しない。画像／標準表示の切替時もG2の操作と音声状態を維持する。取り消された要求・前の人物・停止前の画像を新しい内容として送信しない。仕様10の一覧固定・明示選択・戻る操作を維持する。

SDKの制約は[公式glasses-uiガイド](https://github.com/even-realities/everything-evenhub/blob/main/plugins/everything-evenhub/skills/glasses-ui/SKILL.md)、構成は[公式画像テンプレート](https://github.com/even-realities/evenhub-templates/blob/main/image/src/main.ts)を参照。実機の読みやすさ・画像転送遅延は別途確認する。

## 名前検索

こま（@ai_yorozuya）とスポーツ・IT・投資分野の公開人物を11名追加し、計29名とする。公開一次資料で名前・読み・本人Xへのリンクを確認し、候補を会社なしでも作る。かな・カナ・英字の表記差を既存の正規化で吸収する。未登録の名前は引き続き一般Web検索の対象とする。

本人Xが確認できない人物にアカウントを作らない。取得したプロフィールと根拠で本人性を検証し、同名別人や無関係な会社と結び付けない。「4コマ」「一コマ」「こまを回す」などはこまさんと解釈しない。

「高野／たかの」は利用者が指定した呼称として、公開別名・ASR誤記のカタログから分離する。現在の発話に現れたときだけ「こま（ユーザー指定の呼称・要確認）」を候補にし、選択前の人物解決・本人根拠には使わない。他の姓・地名・食品の一部や、別会社が明示された対象からこまへ置換しない。[登録内容と一次資料](../validation/PUBLIC_PERSON_CATALOG_20260923.md)に根拠を残す。

## 受入条件

- QRN-01：質問は星付きラベルで識別でき、元の事実・質問・引用を失わない。
- QRN-02：質問・出典だけ小文字を要求し、一覧・状態は標準表示。サイズ切替、長文、画像拒否、タイムアウト、遅着を扱う。
- QRN-03：追加した人物は会社なしの公開名・かなから検索候補になり、未確認Xや会社を補完しない。
- QRN-04：高野という指定呼称は来歴付き確認候補に限り、一般語や矛盾する会社を採用しない。
- QRN-05：人物一覧・操作・継続ASR・根拠評価・費用管理・停止境界の回帰を確認する。

HACK-01/05の自律調査と人による対象選択、HACK-02〜04の情報分離・追加API費用なし・失敗時の縮退を維持する。大会と提出要件は変更しない。結果は[検証記録](../validation/QUESTION_READABILITY_20260923.md)へ記載する。

## 同日の接続切れへの対応（Issue #42）

ユーザーは会話中の一時的なリンク切れとスマホに理由が残らない状況を報告。調査時点の公開サーバー・トンネルは正常であり、今回の実機原因は未特定。小文字画像・レイアウト送信の待ち時間だけを従来の2秒から8秒に分離する。マイク・通常文字・接続の2秒期限は維持する。8秒はアプリの設定値であり、実機で測定した最適値ではない。

スマホ上部に直近の停止理由・確認時刻・再開方法を表示し、そのページ内で正常な会話開始が確認されるまで残す。ブラウザーの背景化通知がSDK通知より早くても理由を残す。スマホマイク利用中のG2切断も対象。復旧不能のnative処理待ちでは再開できると案内せず、同じQRから開き直すよう表示する。未完了の転送がある状態で音声を自動再開したり、fatal状態を解除したりしない。理由は端末ページのメモリ内だけに保持する。
