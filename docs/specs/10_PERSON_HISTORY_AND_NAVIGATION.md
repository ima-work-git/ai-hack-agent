# 認識した人物の一覧と質問・出典への移動

2026-09-23のユーザー追加要求。追跡：[Issue #36](https://github.com/ima-work-git/ai-hack-agent/issues/36)。

会話で認識した人物を順番に下へ追加し、利用者が選んだ人物の根拠付き質問と出典を再表示する。[仕様08](08_RESPECTFUL_QUESTIONS_AND_EXPLICIT_AUDIO_CONTROLS.md)のG2「確認なし2回タップで人物固定」は、この仕様の戻る操作へ置き換える。人物固定はスマホの明示ボタンに残す。[仕様09](09_QR_CONVERSATION_START.md)のQR開始と停止条件、本人性・根拠・質問品質・費用の制約は維持する。

## 人物一覧

会話中に抽出された人物と判明した会社を、最初に認識した順で一覧末尾へ追加する。同じ発話から複数の人物候補が抽出された場合も全員を未確認として加えるが、勝手に1人を本人と断定しない。認識したことと本人性を確認できたことを区別する。「調査中」「本人未確認」「確認済みの質問あり」「根拠不足」など、取得結果に応じた状態を表示する。名前だけが現れた項目に他人のカードを付けたり、候補選択を本人確認完了と扱ったりしない。

同じ人物と会社の再認識で行を増やしたり、順番を移動したりしない。同名でも会社が異なる場合は別項目とし、会社未判明の項目を同名だけで既知の会社へ結び付けない。表示には判明している会社も添える。表記補正や別名からの同一人物扱いは既存の本人性・補正確認の規則に従い、一覧の都合でその規則を省かない。

スマホには認識人物の一覧、人物ごとの選択ボタン、質問・出典から「人物一覧に戻る」ボタンを設ける。スマホの一覧は会話中に常時参照できる。G2にも人物一覧を用意し、現在の選択を識別できるようにする。長い一覧は表示範囲を移動し、画面外の人物も選択できるようにする。長い氏名や会社名の表示方法を実機で確認する。

## 質問と出典の再表示

人物を選ぶと、その項目に保存された有効な結果だけを表示する。質問は最大4件で、選択した本人に帰属する事実・質問・出典・引用を一組として扱う。既存のSNS名、投稿日、元投稿や出典リンクも保つ。結果がまだない場合は調査中／未確認／根拠不足を表示し、空きを推測で埋めない。未調査の候補には「未確認」「名前を言い直してください」などの案内を出し、選択だけで有料調査を始めない。

同じ人物・会社の追加調査が失敗／根拠不足でも、以前の有効な根拠付きカードがあれば期限内に限り一部結果として維持する。本人性が曖昧になり確認待ちへ戻った場合は既存カードも破棄し、未確認にする。カードを保持するために本人性の疑問を無視しない。

人物の選択は表示切替であり、録音・ASR・対象リセット・人物固定・有料再検索を呼ばない。一覧を開いたり過去の人物を選んだりしても、会話音声の認識を継続する。スマホで人物を固定する場合は別の明示操作として扱い、履歴閲覧と混同しない。

閲覧する人物と、会話から新しく認識して調査している人物を分ける。会話の初期表示は従来どおり最新の質問を自動表示する。利用者が人物一覧を開いたり過去の人物を選んだりした後は、その閲覧先を保つ。閲覧中に別人物を認識したら一覧末尾を更新し、その人の結果が届いても閲覧画面を切り替えない。一覧表示中に結果が届いた場合も、その人の状態を更新するだけで質問画面を勝手に開かない。閲覧中の本人の追加結果は、同じ人物・画面・出典との対応を保って反映する。出典の確認待ちや本文閲覧中に引用元を別カードへすり替えない。

## G2操作

「人物一覧」と「選択した人物の質問画面」を区別する。確認表示がある場合は、その確認の承認／取消を常に優先する。

| 画面・状態 | 操作 | 動作 |
| --- | --- | --- |
| 人物一覧 | 上下スクロール | 人物の選択位置を移動。録音や調査を操作しない |
| 人物一覧 | 1回タップ | 選択中の人物の質問、またはその人の未確認状態を開く |
| 人物一覧 | 2回タップ | 一覧に留まる。人物固定や音声リセットをしない |
| 質問画面、確認なし | 2回タップ | 人物一覧へ戻る |
| 質問画面 | 下スクロール | 出典への移動確認を出す |
| 質問画面 | 上スクロール | 聞き直しの確認を出す。音声エラー後は既存の再開確認 |
| 出典画面、確認なし | 2回タップ | 同じ人物の質問画面へ戻る。さらに別の2回タップで人物一覧へ戻る |
| 出典画面 | 上下スクロール | 既存の前後の出典／質問画面への移動確認を出す |
| 出典移動の確認中 | 1回／2回タップ | 1回で移動、2回で取消だけ |
| 聞き直し／音声再開の確認中 | 1回／2回タップ | 1回で表示した音声操作を実行、2回で取消だけ |

初期の最新調査画面でカードがまだなく検索候補がある場合は、従来どおり下スクロールで検索候補を移動し、1回タップで再検索を選択できる。この検索候補画面は人物履歴の一覧とは別であり、人物一覧の選択に有料再検索を割り当てない。

確認中の2回タップを「取消して、さらに前画面へ戻る」と二重に解釈しない。戻る場合は取消後に改めて2回タップする。重複イベントの抑止を維持し、一つの操作が戻る・人物選択・音声操作を連続実行しない。3回タップや長押しの独立通知は前提にしない。

## 保持期間と消去

人物一覧と再表示用の結果は、このページのメモリ内だけに保持する。新しい保存API、ブラウザーの永続領域、公開ログへ会話履歴を追加しない。

- 一覧は最大30人。上限を超えたら古い項目から除去し、認識順を保つ。
- 各項目は初回認識から最大15分。再認識、選択、追加結果の到着で保持期限を延長しない。
- カードは自身の有効期限も守る。人物項目が残っていても、期限切れカードを再表示したり、15分まで延長したりしない。
- 停止、画面非表示、切断、ログアウト、認証期限切れ、終了、新しい会話で一覧と再表示用結果を消去する。復帰・再ログインから復元しない。
- G2の背景化・切断・エラー・終了は、スマホのマイク使用中や録音していない手動調査でも停止境界とする。進行中の識別・調査を無効にし、遅着した結果で一覧を復活させない。音声認識のエラー時も一覧・表示中のカード・出典を消し、再開方法とエラー理由を残す。
- 選択中の人物が期限・上限・消去でなくなったら、そのカードと出典を閉じて一覧／待機表示へ戻す。同じ位置へ繰り上がった別人物を勝手に開かない。

停止後や別の会話になった後に古い結果が届いても一覧へ戻さない。結果は対象の人物・要求ID・改訂番号と対応づけ、別人や古い要求の更新を混ぜない。期限切れ後の再調査は既存の明示操作または新しい発話から判断し、一覧の選択だけでは再検索しない。

## 受入条件

- **PH-01**：抽出時の認識順追加と重複防止。同時に認識した複数候補、同名別会社、会社不明、表記補正を混同しない。
- **PH-02**：人物選択で当人の有効な質問・出典だけを再表示し、未確認・取得中・失敗・期限切れを区別する。
- **PH-03**：人物一覧／質問／出典と確認中のG2操作を区別し、2回タップを取消と戻るに二重使用しない。
- **PH-04**：別人物の認識・速報・追加結果でも閲覧を奪わず、人物選択・戻るでASRや有料検索を呼ばない。
- **PH-05**：15分・30人・カード期限、停止／背景／終了／新会話での消去、遅着結果の破棄。
- **PH-06**：QR開始、音声復旧、スマホの人物固定、認証・費用・根拠検証の回帰。

HACK-01/05：AIは会話中の抽出・調査を継続し、人はどの人物の情報を見るかを選ぶ。HACK-02〜04：別人混同、期限切れ表示、意図しない再検索を抑える。HACK-06〜08の大会・提出要件は変更しない。[検証記録](../validation/PERSON_HISTORY_AND_NAVIGATION.md)へ実施後の結果を記載する。
