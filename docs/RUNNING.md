# 実行・設定・復旧

> 2026-09-22 実機復旧対応：本番のG2表示はSDK標準文字を使用します。16px画像方式は画像転送で更新が止まる場合を避けるため明示opt-inへ変更しました。QR認証は非表示中には実行せず、表示された時に再試行します。短文と音声認識状況の表示は維持します。


## まず架空データで動かす

Node.js 24、`npm ci` → `npm run dev` → `http://localhost:4173`。
「架空の会話を入力」から通常／同姓同名／検索障害／根拠なしを確認できます。デモ結果は実APIや実機の証拠ではありません。

本番相当のローカル配信は `npm run build` → `npm start`。サーバーの同一originから画面とAPIを配信します。

## 実APIを有効にする

`.env.example`を`.env.local`へコピーします。鍵をこのリポジトリ、ブラウザー用の`VITE_*`変数、記事、スクリーンショットに含めないでください。

1. `APP_ACCESS_CODE`に16文字以上の利用コードを設定。
2. `ORCAROUTER_API_KEY`、構造化出力対応の`ORCAROUTER_MODEL`、`TAVILY_API_KEY`を設定。
3. USDの1回／1日／大会全体の予算、およびLLM・検索・本文取得の最大見積額をすべて設定。無料の直接ページ取得は`MAX_PAGE_CALL_USD=0`を明示。
4. 必要ならX読取トークン、`X_API_ENABLED=true`、ユーザー1件＋投稿最大5件の合計最大額を設定。自分の開発アカウントが検索対象になるわけではありません。
5. 設定を確認して`AGENT_LIVE_ENABLED=true`、サーバーを再起動。画面で利用コードを入力し「実APIで調査」を選択。

モデル名や価格は固定の推測値を置いていません。選択モデルの最大入出力と現在のサービス料金から、1操作の最大額を保守的に決めます。料金が確定していない場合、成功・失敗とも予約を残します。OrcaRouterのレスポンス中のcost_usdは暫定報告額なので、画面に別表示し、留保額を減らしません。予算ファイルを消して課金制限をリセットしないでください。X利用可能・チャージ済みという申告と、鍵の実接続成功は別です。

OrcaRouterは [Chat Completions](https://docs.orcarouter.ai/api-reference/chat/create-a-chat-completion) と [構造化出力](https://docs.orcarouter.ai/advanced/structured-outputs) を使用します。モデルが非対応ならエラーで止まり、無制限な修復や勝手なモデル変更をしません。

Tavilyはbasic検索を最大5結果に固定します。検索抜粋をそのまま根拠にせず、実際の本文を取得します。JavaScript必須ページ、ログイン壁、Facebook、Xの直接スクレイピングには対応しません。Xは入力に明示した`@handle`、HTTPSの`x.com`/`twitter.com`プロフィールURL、または公開一次情報で事前確認した氏名・会社の対応だけを公開APIで調べ、保護アカウントを拒否します。現在の確認済み対応には「ちょまど＋Microsoft」から`@chomado`への解決があります。任意の日英表記や愛称を推測して同一視したり、Xアカウントへ必ず解決したりする機能ではありません。別名の対応は新しい事実や現在の雇用関係の証明にも使いません。URL・ハンドルだけなら氏名と会社の確認へ戻ります。初回だけXを優先し、追加調査はWebへ進みます。Xの投稿が0件の場合も、追加の投稿ページを課金取得せず、残りの検索枠でWeb調査へ切り替えます。本文の取得枠は初回最大2件・全体最大4件とし、追加調査の枠を残します。取得した文書タイトルと本文から短い引用候補を作り、AIが人物との関係を評価して候補文のIDを選びます。事実・引用は原文から復元し、AIの言い換えを根拠として採用しません。

## 利用コードの入力を省略する

初回は利用コードを入力します。「この端末では12時間、利用コードの入力を省略する」は既定でオンです。記憶させたくない端末ではチェックを外してください。記憶の期限は最初の発行から12時間で、再訪や自動再認証によって延長しません。

記憶するのはランダムな端末認証トークンだけです。会話用とは別のCookieに保存し、`HttpOnly`・`SameSite=Strict`、HTTPSでは`Secure`を設定します。サーバーの`.private/`配下には、そのハッシュと有効期限だけを保存します。利用コードやAPIキーをブラウザーの永続領域、QR、G2パッケージへ保存しません。

有効な記憶があれば、画面を開いた際のPOSTによる復元処理で自動再認証し、新しい短期Bearerを取得します。会話セッションは最大15分のままです。前の結果は「前の内容を再開」を押したときだけ表示し、録音や有料調査を自動で再開しません。「終了して削除」は会話を削除し、この端末の記憶もサーバー側で失効させます。利用コードを変更した場合も、以前の記憶は無効になります。

SafariとEven Appは別の保存領域を使うため、それぞれで初回入力が必要です。Even AppのWebViewがCookieを保持することは実機未確認です。Cookieが消えた場合や12時間を過ぎた場合は、利用コードを再入力してください。

## 音声

会話モードにはサーバー側の`OPENAI_API_KEY`と、音声認識1分あたりの保守的な最大見積額`STREAMING_ASR_MAX_USD_PER_MINUTE`を設定します。`OPENAI_STREAMING_ASR_MODEL`の既定は`gpt-live-transcribe`で、現実装はこのモデルに対応します。鍵や最大見積が未設定なら会話モードは無効です。音声認識はOpenAIの[Realtime transcription](https://developers.openai.com/api/docs/guides/realtime-transcription)へサーバーから直接接続し、人物抽出・調査計画・根拠評価・質問生成にはOrcaRouterを使います。OpenAIの鍵はOrcaRouterの鍵とは別で、どちらもブラウザーへ渡しません。

通常の短い録音には`ORCAROUTER_STT_MODEL`に[input_audio対応モデル](https://docs.orcarouter.ai/advanced/audio-input)、`MAX_STT_CALL_USD`に1回の最大額を設定します。または`STT_API_BASE_URL`・`STT_API_KEY`・`STT_MODEL`をすべて指定したOpenAI互換STTを使用できます。明示STTが優先、部分設定なら停止です。この設定だけでは会話モードは有効になりません。

相手への説明と同意後、「実APIで調査」を選び、同意チェックをオンにします。G2接続時はG2、未接続時はスマホのマイクです。会話モードでは16 kHz・mono・PCM16を同一originのWebSocketへ逐次送信し、サーバーで24 kHzへ変換してOpenAIへ送ります。原音をディスクへ保存しません。

1. 継続して話す場合は「会話モードを開始」を押します。30秒では停止せず、話している途中から認識文字を表示します。約5秒ごとに音声区間を確定し、その発話から氏名と会社名が一組で抽出されると調査を始めます。複数人物や情報不足なら確認へ戻ります。
2. 事実と質問を最大4組、同じ画面で確認します。未確認の枠を推測で補いません。原文の省略は「…」で示し、スマホでカードを押すか「前の出典」「次の出典」で全文・引用・URLを確認できます。
3. 「会話モードを終了」または「中止」で止めます。「終了して削除」は会話と端末の認証記憶も削除・失効させます。通常の短い音声入力は従来どおり最大30秒で、停止後に一度だけ認識・調査します。

会話モードは音声認識と調査を別の接続で進め、調査中も音声を送り続けます。人物抽出・調査は直列で、遅れた場合は最新の確定発話だけを次に処理します。同じ氏名・会社の組は120秒、結果がない場合は30秒の再検索を抑制します。接続準備中の音声は最大2秒分だけを保持し、送信遅延で上限を超えたら停止します。旧来の12秒窓・8秒間隔の録音送信は、現在の会話モードには使いません。

1会話につき人物抽出は最大100回、認証セッションは最大15分です。ストリーミング音声の送信量と接続経過時間の大きい方を基準に、1分単位の上限額を先に予約します。人物抽出・調査も同じ会話の承認済み予算へ集計し、料金未確定の予約を解放しません。通常の短い録音はWAVを一度だけ送り、STTと直後の調査で同じ要求UUIDの予算を共有します。対象調査は20秒、人物抽出と短い録音のSTTは各8秒の上限です。

同意解除、画面の非表示、切断、ページ離脱、認証・費用・回数の上限で停止します。復帰しても録音や有料処理を自動再開しません。すでに送信済みの外部サービス処理まで撤回できるとは保証しません。2026-09-22にPCから公開英語サンプル8秒を送った接続試験では、最初の増分を約0.94秒で受信し、増分7回・確定1回を確認しました。日本語会話、スマホの実際の音質、G2実機の検証を代替する結果ではありません。

## Even G2

既存アプリと同じEven Hub SDK 0.0.12のWebViewブリッジを使います。G2本文を16pxの日本語フォントで描画し、事実・質問の各2行×4組を576×144の画像に収めます。SDK上限に合わせた左右288×144のPNGを順番に送ります。Canvasや画像APIが利用できない、または画像が拒否された場合は通常文字へ縮退します。選択操作はスマホの出典詳細を切り替え、G2の4件一覧は維持します。不足は「未確認」とします。幅を超える全文は画像内へ縮小して描画し、途中で切りません。SDK受付の成功とグラス上で読めることは区別し、実機の読みやすさは未検証です。

会話用QRのアクセス先に`?conversation=1`を指定すると、ログイン後に実APIモードを選び、G2接続を準備します。人物・会社の事前登録や手入力は不要です。会話相手への説明・同意を確認して「会話モードを開始」を押すと、音声から自動で調査を進めます。QRだけで録音や課金処理を開始することはありません。

「使うマイク」でEven G2／スマートフォンを明示選択します。会話用QRではG2を初期選択し、未接続なら接続を試みます。G2に接続できない場合は開始せず、スマホへ自動で切り替えません。入力元はグラス下部にも表示します。

調査結果は途中を「…」で切る方式から、短く完結した表示へ変更しました。既存の根拠評価と同じ呼出内で、原文に実在する28字以内の句と26字以内の質問を作り、原文との一致・省略記号・否定や時制の切り落としを検査します。原文の事実・引用・出典はそのまま保持します。安全に短縮できない場合は全文を画像内へ縮小して描画し、文字を削除しません。追加のAPI呼出は行いません。

会話中はG2下部に入力元（G2／スマホ）、音声接続中・聞取中・調査中・停止・エラーを表示します。聞取中は直近の認識文字も表示し、話題4組を維持したまま最大0.5秒ごとに更新します。同じ本文画像を再送しないため、認識状況の更新でBluetooth転送を増やしすぎません。停止後は認識文字を消し、遅れて届いた音声イベントは表示しません。

現在の確認経路は、UIとAPIを同じoriginで配信するサーバーをEvenアプリのローカルテストQRから開く方式です。スマホからlocalhostは開けません。端末から届くサーバーの`HOST`・`APP_ORIGIN`を設定し、初回は利用コードで認証します。通常QRにはアクセス先だけを含めます。初回入力を省略する専用QRは、認証済み利用者が発行する単回・10分有効のログイン用トークンをURLのフラグメントに含めます。利用コード・APIキー・12時間の端末トークンは含めません。フラグメントはページ起動時に削除し、同一originのPOSTで交換します。発行元のセッション終了・期限切れ・サーバー再起動でも無効になります。QR交換では新規の空セッションを開始し、12時間の端末記憶を設定します。LANに開く場合も鍵や保存データの公開は禁止です。実APIを使う配信はHTTPSにしてください。

```sh
npm run build
npm run pack:g2
```

`.ehpk`は静的画面の梱包確認用で、Nodeバックエンドを含みません。配布版にはHTTPSバックエンドURL、manifestのnetwork whitelist、WebView originに対応するCORS・認証・Cookie再開の検証が必要です。現時点で「このパッケージだけでG2の調査が使える」とは扱いません。min_app_versionは設定値であり、実対応確認済みではありません。[公式ローカル試験](https://hub.evenrealities.com/docs/test/local-testing)・[通信権限](https://hub.evenrealities.com/docs/build/networking)。

## 保存と復旧

- `.private/sessions/`はAES-256-GCMで暗号化。鍵は`.private/.session-key`、端末のファイル権限で保護します。鍵と暗号文を同時に盗まれた場合まで保護する設計ではありません。
- 会話セッションは最大15分。明示終了で個人データとその端末の認証の記憶を削除・失効させ、期限切れも掃除します。12時間の端末記憶は会話の保持期間を延ばしません。再認証でBearerを更新し、前の結果は「再開」操作後のみ表示、マイクや有料調査は自動再開しません。
- 中断時は手動で再調査します。遅れた旧結果は破棄。G2のSDK応答不明や切断時はスマホへ縮退し、実機の残留表示が消えたと断定しません。再接続は明示操作です。
- 429・5xx・本文取得失敗は残る情報へ縮退します。同じ外部操作の無条件再試行はせず、上限内で別資料や追加調査を選びます。未確認の事実は表示しません。
- 予算記録は匿名UUID・UTC日次集計。再起動しても予約を維持。残ったロックや破損ファイルはfail-closedで止めます。実行プロセスが残っていないこととサービス明細を確認してから復旧してください。
- 既定は端末内のみで起動します。OrcaRouter・Tavily・Xの実API疎通とPCからの公開英語サンプルによるストリーミング接続は確認済み。日本語会話・G2実測・実費照合は未完了です。
