## ログ・復旧・ロールバック・撤去

- ログは非識別の実行ID、状態、回数、時間、モデル／API利用量、費用、エラー分類、介入回数に絞る。原音・氏名・全文・APIキー・人物に結び付くURLは永続ログへ残さない。証拠は架空データで再現する。
- 録音・G2接続の障害：録音停止 → スマホに状態表示 → 接続・アプリの前景復帰を確認 → 明示的に新規開始。自動録音再開はしない。
- 調査障害：残る時間・費用・呼出回数を確認 → 設計の範囲で再試行 → 未検証結果は捨て、要確認／情報不足／失敗を表示。手動再試行も日次予算に含める。
- 中断／再起動：再認証後、有効runの保存状態を照会し、利用者の再開操作後に状態を提示する。録音は別途明示開始。明示終了／失効済みなら未完了要求と遅延応答を無効化し、個人情報を復元しない。消去後も日次費用の非識別集計は維持し、再起動で予算がリセットされないことを確認する。
- ロールバック：提出前の動作確認済みコミット・設定版へ戻す。旧版でも録音停止・削除・予算制御が働くことを確認し、互換性不明ならデモを停止して明示した録画に切り替える。
- 撤去担当／日時：[未定]。デモ停止、APIキー失効、課金リソース撤去、セッションデータ削除、日次集計の保持期限と削除、残存課金の確認を行う。
- 提出証拠：[公開リポジトリとコミット]／[3分以内の動画]／[AI HACKと実際のOrcaRouter利用を記載した記事]。実機未達・模擬・未実装を明記する。
