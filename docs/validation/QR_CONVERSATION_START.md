2026-09-23。[仕様09](../specs/09_QR_CONVERSATION_START.md)。追跡：[Issue #34](https://github.com/ima-work-git/ai-hack-agent/issues/34)。

## 状態

基点`fd7fa8fe3b238b243fc724a237c664389b62441b`、ブランチ`fix/qr-autostart-conversation`。開始直後の重複したG2画面復帰通知で録音状態がconnectedへ降格し、mainがASRを止める経路を特定・模擬再現して修正した。実際に背景へ移った場合は従来どおり停止する。またG2開始エラーがcancelで上書きされ、停止表示だけになる経路を修正した。実機ログがないため、ユーザー環境の原因をこの経路だけと断定しない。[仕様08の検証](RESPECTFUL_QUESTIONS_AND_AUDIO_CONTROLS.md)は変更前の開始条件での結果として保持する。

## 検査と独立レビュー

- 認証成功後のG2待ち、単独query非開始、無効QR、記憶済みログインでもQR検証必須、各待機中の停止・背景・終了をDOM操作とAPI/SDKモックで検証。
- 重複画面復帰は録音前後で降格しないこと、実際の背景移行後は再開しないことをSDKイベントで検証。
- 独立レビューで停止後の遅い接続失敗がエラー表示を復活させる指摘を受け、接続とマイク準備の両方へ世代・認証・可視状態の確認を追加した。失敗応答版の回帰試験も成功。
- `npm test`：35ファイル・1,133試験成功。`npm run check`：型・サーバーimport・文書33件のリンク検査成功。`npm run build`成功。公開画面資材は`index-BcXMwc7r.js`。ASRや人物調査の有料実APIを新たに呼んだ検証ではない。

## 実機確認時の記録方法

実施後に基点／対象コミット、試験コマンドと件数、独立レビュー、公開反映を記載する。実機はiPhone・Even App・グラスのバージョンと、QRを開いた環境、表示された準備／聞取状態、途中停止の結果を残す。SDKモックの成功を実機の成功と扱わない。OSのマイク許可で利用者の操作が必要だった場合、その制約を省略しない。

実APIを使った場合は費用とその確認範囲を追記し、計測値と請求確定額を区別する。公開記録にQR秘密、APIキー、会話音声、認識本文、第三者の投稿全文を保存しない。
