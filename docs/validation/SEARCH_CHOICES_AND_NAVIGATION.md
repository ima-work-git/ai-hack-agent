# 検索選択と移動確認の検証

2026-09-23。[仕様](../specs/07_SEARCH_CHOICES_AND_NAVIGATION.md)、[Issue #28](https://github.com/ima-work-git/ai-hack-agent/issues/28)。

## 試験範囲

- main：スクロールで本文を変えず確認、単タップ移動／ダブル取消、ASR継続、固定／聞き直しとの分離。実検索語の表示、候補選択、選択待ち中の中止と古い応答破棄。
- HTTP：提示済み候補IDのみ受理。他セッション・別origin・任意target・架空IDを拒否。新要求は一度限り・同一会話の予算、保持期限とリセットで候補を無効化。
- provider：送信直前の実際のWeb検索語・Xハンドル／検索式・SNSプロフィールURL。初回／追加／過去／SNS、キャッシュ・取消を区別。
- catalog/helper：3名の公開名と読み、かずなりのASR誤記を要確認の候補として提示、Taishiの活動説明を会社と同一視しない。短いかな名の通常語への誤一致を除外。
- 推奨質問：根拠factIdをLLMが選び質問を生成する既存経路を確認。過去投稿の具体的質問を表示時に定型文へ置き換える箇所を修正し、時点の文脈を添えて具体性を維持。

## 独立レビュー

候補検索中に聞き直すと候補選択中フラグが残る問題と、音声エラー後の再開タップを古い画面確認が消費する問題を指摘・修正した。両方の回帰試験を追加した。追加レビューでは、移動確認中の追加結果で表示中カードと出典の版がずれる問題を修正。出典ID・引用文・ページ位置で追跡し、取消後は同じ画面の最新内容へ同期する。独立した最終レビューでblocking所見なし（関連228件を独立実行）。

## 実API

初回のかずなり・TaishiはX/Web取得後の本人照合で停止した。Web取得2件の順序を、読みの資料より本人と現行Xを接続する一次資料優先へ修正した。Taishiでは会社名なしを意図した調査モードと取得済み一次プロフィールの所在をモデルへ明示した。所在情報だけで本人性を承認せず、モデルの判定と既存の本文検査を維持する。

| 入力 | 実API結果 | 時間・範囲 |
| --- | --- | --- |
| かずなり | 本人性を確認し質問4件。最近X1・過去X1・人物情報2 | 最終約18.7秒。最近投稿の根拠不足分を人物情報で補完 |
| Taishi AI Language Learning App | 速報3件→追加4件→SNS評価後は根拠のある3件。X・Facebookの質問を表示、Instagram本文も取得 | 速報約9.3秒、4件約25.8秒、最終約50.9秒 |
| 株式会社CyberACEの宇佐美良治 | 本人性を確認し質問4件。最近X2・過去X1・人物会社1 | 最終約20.5秒 |

すべての表示カードで推奨質問の生成を確認した。短い表示質問が安全に得られない場合は全文へ戻る。取得・評価結果に依存するため、4件や希望の配分を常時保証しない。会社名や有名さを理由に本人性を無条件で承認する変更はない。投稿本文・実会話・秘密値は公開記録へ保存しない。料金は全事業者分が確定しておらず、一部API報告額を総実費とは扱わない。
