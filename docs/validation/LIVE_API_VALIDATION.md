## 検出した問題と変更

- Xが0件の場合は、空の根拠でLLM評価を行う前にWeb調査へ移る。検索2回・本文4件・20秒の既存上限を守る。
- 本文にはなく実ページのtitleに氏名がある例に対応し、実際の文書タイトルを保持する。検索結果のタイトルやスニペットは本人確認の根拠に追加しない。
- モデルに引用文・事実を書き直させず、取得本文に実在する候補文のIDを選ばせる。1資料10,000文字内、引用1,000文字以下・最大4枠、完全に含まれる200文字以下の文を各枠最大8件。長文や切断文は候補化しない。名前・会社の共起だけでは本人の事実と認定せず、モデルに帰属と矛盾を評価させる。最終段階でも出典・対象名・所属・事実の包含を再検査する。
- 評価ごとに候補IDを変更し、古いID、捏造ID、モデルが付加した任意の事実・出典・引用を拒否する。別人への意味的な誤帰属は文字列検査だけで完全には防げないため、評価集合による検証を残す。
- HTML属性やscript中の`</head>`、非表示のtemplate等が本文へ漏れるケースを独立レビューで修正。不正な構造では本文を採用しない。
