## 障害ごとの仕様

数値は空欄のまま実装に進まず、再試行は下記上限と業務全体の予算・期限の両方で制限します。

| 障害 | 検知 | 再試行 / 復旧 | 停止・通知 / 保存する証拠 |
| --- | --- | --- | --- |
| 429 | [HTTP状態・応答] | [Retry-After尊重、指数バックオフ + ジッター、最大__回] | [上限で要対応、試行数・待機時間] |
| タイムアウト | [接続__秒 / 応答__秒 / 全体__秒] | [副作用の有無を照会し、安全な場合のみ再試行] | [結果不明として保存、重複送信を防止] |
| 5xx | [HTTP状態] | [実行結果を照合、最大__回で再試行] | [連続__回で停止 / 通知] |
| 不正なAI応答 | [構造・必須値・許可操作・意味の検証] | [修復最大__回。検証前に道具を実行しない] | [失敗理由を記録して要対応] |
| 部分成功 | [操作台帳と外部結果の照合] | [未完了だけ再開 / 許可済み補償操作] | [成功分・残作業・補償結果を提示] |
| 予算上限 | [実費 + 実行中の見込額 + 次操作見積] | [新規モデル / 道具実行を停止、状態保存] | [残作業・消費額・承認済み再開条件を通知] |
